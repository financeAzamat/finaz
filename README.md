# finaz

Статический сайт консалтинг-практики finaz.

Без сборки и зависимостей: HTML + CSS, шрифты с Google Fonts.
Открывается как есть - `open index.html`.

- `index.html` - главная
- `case.html` - кейс: контроль строительства
- `tokens.css` - дизайн-токены
- `bg.css` - фон страниц
- `images/CREDITS.md` - атрибуция фотографий (сохранять при любых правках)
